A1.1 · Estudio comparativo de tecnologías
Objetivo: justificar con criterio la elección de una tecnología de desarrollo móvil.

Elige tres tecnologías de familias distintas (por ejemplo: Android nativo, Flutter y PWA) y compáralas.

Android nativo: App para registrar códigos de barras para hacer inventarios en una tienda. 
La app solo necesita Android para funcionar en los disipositivos de scanner, así que el ahorro
de Flutter no aporta demasiado, y el bluetooth de bajo nivel funciona mejor en nativo

Flutter: App de un gimnasio. Los clientes pueden tener android o iOs. Las ufncionalidades
no requieren demasiada complejidad así que el multiplataforma supone un ahorro sin grandes
defectos

PWA: La carta de un restaurante, porque funciona desde web y se abre escaneando el QR en la
mesa o en la carta. No requiere al usuario descargar una aplicación y los precios se actualizan
cuando quieran, sin compilar ni publicar
